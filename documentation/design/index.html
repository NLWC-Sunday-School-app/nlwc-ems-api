Warm, trustworthy, unmistakably NLWC, and built for safeguarding.

One system for four surfaces: public site, attendee portal, admin console and check-in PWA. It inherits the ember gradient from the logo and the Plus Jakarta Sans voice of nlwc.church, but it is tuned for the thing this product really is: money, children and capacity. Full specification in DESIGN_SYSTEM.md.

Clarity over decoration

Every state is word + icon + colour. Colour never carries meaning alone.

Separate things look separate

Registration, payment, booking and attendance each get their own status axis, never one merged badge.

Safe by default

Destructive and custody actions are never one tap, never green-by-default, always audited.

Core components

Buttons

Primary (ember-600, white text) is the default. Brand (website orange, dark text) is for dark headers and event heroes. One primary or brand button per view. Disabled buttons must say why (adjacent text), never silently.

Domain patterns

These exist because the BRD says "an account is not a registration, a registration is not a payment, a payment is not a room, a QR is not custody." The UI must make that visible.
