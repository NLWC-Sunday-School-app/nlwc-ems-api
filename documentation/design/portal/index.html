Frequently asked questions

Will there be Bible Museum this year?

No, there will not be Bible Museum this year.

Will there be Christmas party this year?

No, there will not be Christmas party this year.

When is Boot Camp ending?

Boot Camp is ending on 23rd December, 2026.

When can we start picking up campers?

Campers can be picked up on 23rd December by 6PM latest.

Will there be interhouse sport at this year's Bible Boot Camp?

No, there will not be Interhouse sport at this year's Bible Boot Camp.

Can children from age 17 and above camp?

No. They can only come in as walk-in participants daily. Only children from age 10 to 16 are allowed to camp.

Can we know more about the ministry?

Yes, you can visit nlwc.church for more info about the ministry.

Will there be parent interactive forum?

No, there won't be a parent interactive forum this year, but parents can stream the training sessions for the virtual Boot Camp sessions.

Are adults allowed to come for Bible Boot Camp?

No, Bible Boot Camp is majorly for children. However, there are sessions for adults at the virtual Boot Camp sessions.

How can we give towards this event?
